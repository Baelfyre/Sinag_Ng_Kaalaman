# Branding Assets

## Sinag ng Kaalaman logo

`sinag-ng-kaalaman-logo.webp` is the current approved project logo derived from the logo concept generated specifically for Sinag ng Kaalaman during project ideation.

### Visual concept

- **Sun / rays:** knowledge, discovery, and illumination
- **Open book:** learning and education
- **Sprout:** growth and developing understanding
- **Blue:** learning and clarity
- **Yellow / orange:** light, energy, and encouragement
- **Green:** growth and progress

### Usage

Use the full logo for:

- project README and repository presentation
- onboarding or landing surfaces
- main dashboard branding
- project documentation

For small UI locations, a simplified emblem may be created later from the same approved visual language.

Do not redesign, recolor, crop, or create derivative brand marks as canonical assets without design review.

### File note

The committed WebP is an optimized repository copy intended for web and documentation use. The original generated image remains the source-quality reference outside this repository snapshot.

No standalone third-party asset license is attached to this project-specific generated artwork. Any future repository-wide licensing decision should explicitly address project branding assets.
